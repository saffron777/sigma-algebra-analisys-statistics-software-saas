# Free Software Directory (FSF)

Directorio: <https://directory.fsf.org/>

## Ficha del paquete

- **Nombre:** Sigma Algebra Analisys Statistics Software (SAAS)
- **Nombre corto:** Sigma Algebra
- **Descripción:** Self-hosted statistics and reporting web application. Import CSV, Excel, text,
  SQL Server, MySQL/MariaDB, PostgreSQL, Oracle, MongoDB and JSON APIs; descriptive statistics,
  hypothesis tests, regression/ANOVA, surveys, SPC/DOE, charts and PDF/Word/Excel reports.
  Multi-user and AGPL-3.0-or-later.
- **Licencia:** GNU AGPL v3.0 or later (`AGPL-3.0-or-later`).
- **Código fuente:** https://github.com/saffron777/sigma-algebra-analisys-statistics-software-saas
- **Tarball de release:** `sigma-algebra-analisys-statistics-software-saas-1.0.0.tar.gz` (adjunto a la
  release de GitHub).
- **Dependencias principales:** Python 3.11+, Flask, pandas, NumPy, SciPy, statsmodels,
  scikit-learn, SQLAlchemy, Plotly; Node.js solo para compilar los assets del frontend.
- **Documentación:** README.md, docs/DEPLOYMENT.md, docs/DEMO.md.
- **Demo:** https://demo.tudominio.org
- **Mantenedor:** Frank Miranda <frank.alexis@gmail.com>
- **Requisitos del sistema:** Linux con Docker (recomendado) o Python 3.11+; SQLite por defecto.

## Pasos

1. Crea/edita la ficha mediante el formulario de envío del FSD.
2. Adjunta el enlace al tarball de release y al código; indica la licencia AGPL.
3. Responde a la revisión de «free software»; el directorio puede pedir que confirmes que no hay
   dependencias propietarias obligatorias.
4. Añade el enlace al README del proyecto cuando esté aprobado.

> El FSD revisa el software y puede tardar; no es un canal de lanzamiento inmediato.
