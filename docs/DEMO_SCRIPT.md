# Guion del vídeo/demo (60–90 s)

Objetivo: mostrar en menos de 90 segundos que Sigma Algebra es una aplicación estadística completa,
autoalojada y libre, y llevar a la demo o al repositorio.

## Antes de grabar

- Usa una instancia limpia con los datos de ejemplo cargados y el usuario demo.
- Resolución 1440×900 o 1920×1080, navegador sin marcadores ni pestañas personales.
- Ten a mano `docs/screenshots/` y la demo pública.
- Graba en español; añade subtítulos en inglés. Versión corta para redes: 30 s.
