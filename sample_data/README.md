# Datos de ejemplo

Los archivos de esta carpeta son **sintéticos**: se generan con
`python scripts/make_sample_data.py` a partir de distribuciones aleatorias con semilla fija.
No contienen datos de personas, empresas ni clientes reales.

Se distribuyen bajo **CC0-1.0** (dominio público) para que puedas usarlos, modificarlos y
compartirlos sin restricciones. Si prefieres la licencia del proyecto, la AGPL-3.0-or-later
también se aplica al conjunto de la obra.

Archivos:

- `ventas.csv`: 300 registros mensuales de ventas con variables numéricas y categóricas.
- `encuesta.csv`: respuestas sintéticas de una encuesta de satisfacción.
- `marco_muestral.csv`: 1 000 hogares sintéticos agrupados por distrito y manzana.
- `analisis_demo.ipynb`: notebook de demostración que usa el dataset de ventas.
